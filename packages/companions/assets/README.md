# Companion default artwork

Bundled default images for the companion image slots: `roy/` and `roya/`, each with `hero.jpg`, `avatar.jpg`, `gallery-0.jpg`, and `gallery-1.jpg`.

These are original AI-generated painted illustrations made for After Hours. The characters are fictional parody companions, not depictions of real people. Overrides belong in the git-ignored manifest described in `docs/architecture.md`.
